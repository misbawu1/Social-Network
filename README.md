# Commonroom

A small, beginner-friendly starting point for a campus community social network. This first version is a static front-end, built with plain HTML, CSS, and JavaScript so it is easy to open, understand, and extend.

> **Project description:** A beginner-friendly campus social network where students can connect, share updates, and stay informed about their community.

## Open the project

Open `index.html` in a browser. No package installation or build step is needed.

## What works so far

- Responsive campus feed with sample posts and announcements
- Write and publish a post in the current browser session
- Like and save posts
- Follow and unfollow suggested people
- Filter the feed by posts and announcements

Posts are temporary and reset when the page is refreshed. Accounts, persistent storage, real image uploads, messaging, and admin tools are good next steps for future versions.

## Project files

- `index.html` — page structure and sample content
- `styles.css` — colors, layout, and responsive styles
- `script.js` — simple browser interactions

## A good next step

Learn the existing page first, then add one small feature at a time. A natural next milestone is saving posts in the browser with `localStorage`, followed by a real backend and sign-in.
